# Big Data Platforms Course

This [course](https://github.com/rdsea/bigdataplatforms) covered the core concepts and technologies behind big data platforms, including platform design, core services for storage, data ingestion (ETL), processing pipelines, and large-scale data processing. Theoretical topics were also addressed, including reliability, data governance, and data quality management. Both development and operations aspects of big data platforms were included.

The course consisted of three major assignments, each combining theoretical design with practical implementation:

- **Assignment 1**: Design and development of a basic big data platform with core components such as data storage and ingestion.
- **Assignment 2**: Focused on data ingestion and ETL, covering both batch and real-time ingestion and transformation.
- **Assignment 3**: Focused on real-time streaming data processing and analytics.

Each assignment’s design and implementation can be found in its respective subdirectory.

**Technologies used**:

- Apache Kafka
- Apache Cassandra
- Hadoop & HDFS
- Apache Spark  
- Apache Flink
- Apache Airflow
- Docker & Docker Compose
- Python libraries such as PySpark and Pandas

Deployments were carried out on **Google Cloud Platform**. The primary programming language was **Python** with some use of **Bash** scripts.
